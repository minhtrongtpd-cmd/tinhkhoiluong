# Tính khối lượng mua

Công cụ tính khối lượng mua cổ phiếu theo mức lỗ chấp nhận:

**Khối lượng = Số tiền chấp nhận lỗ ÷ Lỗ mỗi cổ phiếu**

## Tính năng

- Vào lệnh 1 lần hoặc chia 3 công thức (lệnh 1, lệnh 2, lệnh 3 nhồi thêm bằng lãi và tiền vay)
- Tính phí mua/bán, thuế bán, lãi vay, làm tròn xuống theo lô
- Hiển thị lỗ lớn nhất ở từng giai đoạn, lãi tại giá mục tiêu, tỷ lệ lãi/lỗ
- Nhật ký lệnh và phân tích tỷ lệ thắng theo mã, theo công thức
- Sao lưu và khôi phục dữ liệu

Dữ liệu lưu trong trình duyệt của bạn (localStorage), không gửi đi đâu.

## Đưa lên GitHub Pages

1. Vào https://github.com/new, đặt tên repo (ví dụ `tinh-khoi-luong-mua`), chọn **Public**, bấm **Create repository**.
2. Bấm **uploading an existing file**, kéo thả file `index.html` (và `README.md`), bấm **Commit changes**.
3. Vào **Settings → Pages**. Ở mục **Branch** chọn `main`, thư mục `/ (root)`, bấm **Save**.
4. Chờ 1 đến 2 phút, trang chạy tại: `https://<tên-github-của-bạn>.github.io/tinh-khoi-luong-mua/`

Lưu ý: nếu mở trang bằng link khác nhau (tên miền khác nhau) thì lịch sử lệnh không dùng chung, vì dữ liệu gắn với từng địa chỉ trang. Hãy dùng sao lưu để chuyển dữ liệu.
